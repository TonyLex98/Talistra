Политика конфиденциальности

Дата публикации: 29 июля 2026 года

Главное

Talistra — локальная читалка. Приложение не требует регистрации, не содержит рекламы и не передаёт разработчику книги, историю чтения, настройки, выбранные слова или результаты перевода.

Какие данные обрабатываются

Документы, прогресс, статистика, закладки, заметки, словарь и настройки сохраняются только на устройстве пользователя. Приложение получает доступ лишь к файлам, которые пользователь сам выбрал через системный интерфейс Android. Резервная копия создаётся только по команде пользователя и сохраняется туда, куда он сам её положит.

Чтение вслух выполняет встроенный в устройство синтезатор речи; приложение само текст никуда не отправляет.

При сбоях приложение ведёт на устройстве технический журнал ошибок — тип и место ошибки, без содержимого книг. Он отправляется разработчику только вместе с обратной связью и только если пользователь сам включил «Приложить журнал ошибок».

При добровольной отправке обратной связи обрабатываются текст сообщения, необязательное имя, необязательный контакт для ответа, время отправки и технический сетевой адрес, необходимый для защиты формы от спама. Эти сведения не продаются и не используются для рекламы.

Для чего нужен интернет

  • для однократной загрузки выбранной языковой модели офлайн-перевода;
  • для открытия сайта talistra.ru;
  • для отправки обратной связи по явному действию пользователя.

Хранение и удаление обращений

Сообщения обратной связи хранятся на защищённом сервере Talistra только для обработки обращения и развития продукта. Пользователь может запросить удаление сообщения, указав использованный контакт и содержание обращения через форму обратной связи.

Передача третьим лицам

Данные обратной связи не передаются третьим лицам, кроме случаев, прямо предусмотренных законодательством. Серверная инфраструктура может технически обрабатывать сетевой трафик для доставки сайта и защиты от атак.

Изменения политики

При существенных изменениях новая версия политики будет опубликована на этой странице с обновлённой датой.
